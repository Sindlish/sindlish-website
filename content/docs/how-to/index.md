How-to guides solve a problem from start to finish. They are not a teaching ladder, but short recipes you can reach for after finishing the Learn path.

Each guide assumes you have read the basics: variables, functions, loops, and at least a passing familiarity with the error classes. Every runnable example block on these pages has been checked against the interpreter.

| Guide                                                     | What you learn                            |
| --------------------------------------------------------- | ----------------------------------------- |
| [Number guessing game](/docs/how-to/number-guessing-game) | Build a small terminal game from scratch  |
| [Read and parse user input](/docs/how-to/parse-input)     | Safely turn text from `puch` into numbers |

These pages lean on `puch`, Sindlish's input function. `puch` reads a line from the terminal, so the interactive examples run best when you use the `sindlish` CLI. The online interpreter's browser environment does not provide a terminal.
