Variables

Store values in named variables and declare their types.

A variable is a name that points to a value. Writing umar = 25 stores the number 25 under the name umar, and from then on you can use umar anywhere you would type 25.

The type key you pair with the value is written exactly like the type: adad for whole numbers, dahai for decimals, lafz for text, faislo for true or false. The full set is short:

Keyword Meaning Holds
adad whole number 25
dahai decimal 9.5
lafz text "Karachi"
faislo true or false koorh
pakko fixed, read only any of the above

Note

If you declare a typed variable without a value, Sindlish fills in the type's default. Numbers start at 0, empty text at "", and booleans at koorh (false).

Real content on purpose: the four-column method tables elsewhere in the docs are the worst case for judging sidebar crowding, and the nav here carries the full 33-page tree.
